# Churrinche kit

The shared Godot addon, Claude skills and templates for Churrinche Games: a portfolio of small, free, open-source, Argentine-themed Android games (each game is its own repo, Play app and itch.io page). Also home base for the portfolio's design.

**Start here:** read [docs/superpowers/specs/2026-11-21-portfolio-design.md](docs/superpowers/specs/2026-11-21-portfolio-design.md). It has the intent, the brand, open source and donations, art direction, the stack, how code and skills are shared, the game catalog and the release process.

## Repo

- Local git only, no remote. Pushing anywhere happens only when Juan says so. The future home is `github.com/churrinche-games/kit` (public).
- Games vendor `addons/churrinche_kit` from a kit **tag** with the sync script, which also copies `.claude/skills/`. Every release is a semver tag; a breaking change bumps the major. Never move or delete a tag.
- Games: each in `~/src/<game>`. `~/src/sudoku` is Bichoku's old web version; the Godot port is a new repo.

## Environment

- Godot 4.7.2 at `/Applications/Godot.app/Contents/MacOS/Godot`.
- Not installed yet (ask Juan first): JDK 17, Android SDK 35+, export templates, gdtoolkit, butler.

## Architecture

Not scaffolded yet. Planned:

```
addons/churrinche_kit/   the runtime addon games vendor
  about/ more_games/ feedback/ rating/ sound/ save/ i18n/ theme/ mobile/
addons/gut/              test framework (pinned, vendored)
tests/                   GUT tests for the kit
.claude/skills/          vetted third-party skills + our own; THIRD_PARTY.md
templates/               files the new-game skill copies
tools/                   sync script, art and sound generators
docs/superpowers/specs/
```

- Kit code must not know about any specific game.
- Art and sound are generated by scripts in the repo; outputs are reproducible.

## Conventions

- Code, comments, commit messages and docs in English. Interface text in rioplatense Spanish and English.
- **TDD is the rule:** write a failing test first, watch it fail, then write the minimal code to pass.
- Feature folders; tests in `tests/` mirroring them. Pure logic in plain `RefCounted` scripts, out of nodes and scenes.
- Static typing in GDScript everywhere.
- Pin new dependencies to existing major versions; don't add a dependency when a few lines will do.
- Keystores and passwords never enter the repo.
- Never add co-author or AI attribution to commits or PRs.
- Commit to `main`; push only when asked.
