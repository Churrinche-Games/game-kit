# Churrinche kit v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `~/src/game-kit` into a working Godot 4.7 project with tests, lint and one check command; vendor GUT and the vetted skills at pinned commits; add the first kit module (versioned save file); and add the sync script games use to vendor a kit tag. Tag it `v0.1.0`.

**Architecture:** The kit repo is itself a Godot project so the addon is tested in place. Third-party code (GUT, skills) is copied in by one script from a lockfile of `repo + commit`, so vendoring is reproducible and auditable. Games get the kit with `tools/sync-kit.sh`, which copies from a git tag with `git archive`, never from the working tree.

**Tech Stack:** Godot 4.7.2 (GDScript, static typing), GUT 9.7.1, gdtoolkit 4.5.0 (`gdlint`, `gdformat`), bash, git, `gh`/curl for fetching.

**Spec:** `docs/superpowers/specs/2026-11-21-portfolio-design.md` (sections: Claude skills in every project, Shared kit, Repos and code sharing). Also `CLAUDE.md`.

## Global Constraints

- Godot binary: `/Applications/Godot.app/Contents/MacOS/Godot`; scripts read `${GODOT:-/Applications/Godot.app/Contents/MacOS/Godot}`.
- Static typing in GDScript everywhere; pure logic in plain `RefCounted` scripts, out of nodes and scenes.
- Kit code must not know about any specific game.
- English code, comments, commits and docs.
- **TDD is the rule:** failing test first, watch it fail, minimal code, watch it pass.
- Pin dependencies to existing majors; GUT `v9.7.1`.
- Vendored skills, exactly these, read in full and vetted on 2026-11-21:
  - `jame581/GodotPrompter` (MIT) @ `426e8ab597473d1c71a11a04f6f0f2e1182a8e39`: `gdscript-patterns`, `godot-testing`, `mobile-development`, `export-pipeline`, `localization`, `responsive-ui`, `audio-system` (from `skills/<name>`).
  - `gamedev-skills/awesome-gamedev-agent-skills` (Apache-2.0) @ `c6ca6c41c839b68319ffc08430b99ab768debc32`: `godot-gdscript-headless-testing` (`skills/godot/…`), `puzzle` (`skills/genres/…`), `game-feel` (`skills/disciplines/…`).
- Vendored code keeps its license files; `THIRD_PARTY.md` lists each item with source, commit and license.
- Every release is a semver tag; never move or delete a tag. Local git only, commit to `main`, push only when Juan says so.
- Never add co-author or AI attribution to commits.

## Review Focus

1. **A crash in the middle of saving** (half-written file): the previous save must survive. `save_data` writes `<path>.tmp` then renames; covered by `test_leftover_tmp_is_ignored` and `test_save_replaces_atomically`.
2. **A save written by a newer version of the game** (the player downgrades or a test build): must not be destroyed. It is moved to `<path>.broken` and defaults are returned; covered by `test_newer_version_is_backed_up`.
3. **Valid JSON with the wrong shape** (an array, `data` not a dictionary, `version` missing or a string): defaults, file backed up, no crash; covered by `test_wrong_shape_is_backed_up`.
4. **Godot's JSON turns every number into a float**, so `level: 3` comes back as `3.0` and breaks `match` and array indexing in games. Values whose default is an `int` come back as `int`; covered by `test_int_defaults_come_back_as_int`.
5. **Syncing over a game with local edits to its vendored copy**: must refuse, not overwrite silently; covered by `test_refuses_dirty_game`. A missing tag must fail with the game untouched; covered by `test_missing_tag_fails`.

### Task 2: Versioned save file (`SaveStore`)

**Files:**
- Create: `addons/churrinche_kit/save/save_store.gd`
- Test: `tests/save/test_save_store.gd`

**Interfaces:**
- Produces: `class_name SaveStore extends RefCounted`
  - `func _init(path: String, version: int, migrations: Dictionary = {}) -> void` — `migrations` maps `from_version: int` to `Callable(data: Dictionary) -> Dictionary` that returns data for `from_version + 1`.
  - `func load_data(defaults: Dictionary) -> Dictionary`
  - `func save_data(data: Dictionary) -> Error`
- File format: JSON `{"version": <int>, "data": {...}}`.
- Rules for `load_data`, in order:
  1. No file → `defaults.duplicate(true)`.
  2. Not JSON, not a dictionary, `version` not a number, `data` not a dictionary, or `version` greater than the store's → move the file to `<path>.broken` (replacing an older `.broken`) and return a copy of `defaults`.
  3. Older `version` → apply migrations `v, v+1, …` up to the store's version; a missing migration step counts as broken (rule 2).
  4. Result = copy of `defaults`, overlaid with loaded keys; keys not in `defaults` are kept; a loaded `float` whose default is an `int` becomes `int`.
- `save_data` writes `<path>.tmp`, then renames over `<path>` (`DirAccess.rename_absolute`); creates the parent directory if missing.

Tests use paths under `user://test_saves/` and delete that directory in `before_each`.

- [ ] **Step 1: Write the failing tests** in `tests/save/test_save_store.gd`:
  - `test_missing_file_returns_defaults`: `load_data({"level": 1})` == `{"level": 1}`.
  - `test_round_trip`: save `{"level": 4, "name": "Ñandú"}`, a new `SaveStore` with the same path loads it equal.
  - `test_int_defaults_come_back_as_int`: after a round trip, `typeof(result.level) == TYPE_INT`.
  - `test_new_default_keys_are_filled`: saved `{"level": 2}`, loaded with defaults `{"level": 1, "sound": true}` → `{"level": 2, "sound": true}`.
  - `test_garbage_is_backed_up`: file contains `not json{`; returns defaults; `<path>.broken` exists with the same content.
  - `test_wrong_shape_is_backed_up`: three cases (`[1,2]`, `{"version": 1, "data": [1]}`, `{"version": "1", "data": {}}`) each return defaults and leave `.broken`.
  - `test_newer_version_is_backed_up`: file at version 3, store at version 2 → defaults, `.broken` exists.
  - `test_migrations_run_in_order`: file at version 1 `{"lvl": 5}`; store version 3 with migrations `1: rename lvl→level`, `2: add "stars": 0`; result `{"level": 5, "stars": 0}`.
  - `test_missing_migration_is_backed_up`: file at version 1, store version 3, only migration `2` given → defaults, `.broken`.
  - `test_leftover_tmp_is_ignored`: a valid save plus a garbage `<path>.tmp` → loads the valid save.
  - `test_save_replaces_atomically`: after `save_data`, `<path>.tmp` does not exist and `save_data` returned `OK`.
- [ ] **Step 2: Run** `tools/check.sh`. Expected: the tests fail on unknown `SaveStore`.
- [ ] **Step 3: Implement** `save_store.gd` to the rules above.

  - Copies, from `git archive <tag>` of the kit, these paths into `<game-dir>`, replacing what is there: `addons/churrinche_kit`, `addons/gut`, `.claude/skills`, `THIRD_PARTY.md` (written to `<game-dir>/addons/churrinche_kit/THIRD_PARTY.md`).
